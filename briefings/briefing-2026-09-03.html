Model Watch
1. DeepSeek Harness (dsh) — the open agent runtime
MomentumExplosive SentimentPositive Production ReadyMedium Hype RiskHigh ConfidenceHigh
What is happening

DeepSeek shipped dsh on Aug 13, 2026 as an MIT-licensed agent runtime built on a TypeScript microkernel where "everything is a plugin" — model adapter, tool registry, sandbox, session log, scheduler and UI are all replaceable, including the agent loop itself. It crossed ~147K stars in four days and now sits at 207K+ stars, running Claude Code and Codex as plugins. Its standout production feature is an append-only trajectory log giving full replay of every tool call.

Capabilities & benchmarks

No model benchmarks — dsh is a harness, not a model. Its competitive claim is the inverse of Claude Code: Claude Code is the deepest but closed harness (≈30 lifecycle hooks); dsh is an open one where you can inspect and replace the core implementation. The trajectory log is the feature most likely to win production teams that need auditability.

Who is using it

Adoption is currently developer-community-driven (the star velocity is real but production-deployment evidence is thin). The framing is corroborated by Theo (T3 Code), who has moved to a multi-harness orchestration model, and by InfoQ/36Kr reporting that major coding-tool founders (Amp's Thorsten Ball: "the model is dead"; OpenCode's Dax Raad) now argue models no longer create daily-programming gaps and that the harness is the differentiator.

Engineering implication

The agent loop is being unbundled from any single vendor's model. For teams that value inspectability, replay, and self-hosting, dsh is now the leading open option — but treat the star count as hype until your team has run it against a real codebase. Verdict: Trial. Spin up dsh alongside your existing harness to compare the trajectory-log audit story; do not migrate production yet.

What is happening

Zhipu/Z.ai's GLM-5.3-Flash (320B MoE, 18B active, MIT license, 1M context) ran anonymously as "Ox Alpha" on OpenRouter for six days — free, undocumented — and served ~62 trillion tokens before being identified, ending DeepSeek's 56-day streak at the top. It scores 57 on the Artificial Analysis Intelligence Index (above DeepSeek V4 Pro's 53) at roughly 1/40th of Opus pricing.

Capabilities & benchmarks

Natively multimodal (text/image/video input), promo pricing $0.075/$0.25 per M tokens. On the Agentic Index it tied Opus 5 for #1. The unverified claim that 100,000 Chinese-made chips served it remains unconfirmed by CNBC; treat the chip-sovereignty narrative as a claim, not evidence.

Who is using it

Real production traffic at volume: it topped OpenRouter weekly usage and OpenRouter data shows DeepSeek V4-Flash leads weekly token share at 22%, with DeepSeek, Tencent Hy3, and Xiaomi MiMo as the top three. Theo audited 1,000+ PRs in T3 Code on GLM-5.3-Flash for $0.12 vs ~$100+ on Fable, arguing it behaves better in agentic workflows than models costing 10–100× more.

Engineering implication

For cost-sensitive agentic workloads (PR review, bulk classification, on-task coding loops), the MIT-licensed Flash tier is now a credible default. Run it on a parallel lane and route by task type. Verdict: Adopt for high-volume/low-stakes tasks; Watch the chip-sovereignty claim for supply-chain risk.

1. Harness engineering — now the dominant production thesis
MomentumExplosive SentimentPositive Production ReadyHigh Hype RiskLow ConfidenceHigh
What is happening

This run produced three independent, high-quality corroborations of the harness-engineering thesis (first seen 2026-09-01). (1) DeepSeek open-sourced dsh as a fully-pluggable harness. (2) Maersk's Dmitry Buykin stated plainly: "the agent is not the system; the refining loop around the agent is the system," describing a three-part architecture of SOP corpus + execution runtime + feedback loop fed by 100,000+ corrections. (3) Coding-tool founders (Amp, OpenCode, Pi) now argue publicly that models no longer create daily-programming gaps and that the harness is the only differentiator labs can control.

Why it matters

The primary engineering lever has moved decisively from model choice to the execution harness — tool design, the agent-computer interface, the refining loop, and configuration files (CLAUDE.md / agents.md / skills). The 2026 harness-optimization paper that lifted Terminal-Bench 2 pass@1 from 69.7% to 77.0% with no prompt change remains the cleanest single datapoint.

Evidence from real teams

Maersk (200+ concurrent production instances, 5–10 min latencies, "process memory" corpus 20× larger than runtime); DoorDash Flux (130,000 tasks); Anthropic's Mike Krieger (Claude Code tags now the majority of internal usage, delegation shifting from tasks to end-states); Theo's T3 Code (multi-harness orchestration).

Engineering implication

Invest harness-engineering effort where it compounds: trajectory logs, feedback loops that rewrite the corpus, and pluggable tool/sandbox design. Stop tuning prompts as the primary lever. Verdict: Adopt.

2. Trajectory evaluation & append-only replay logs
MomentumHigh SentimentPositive Production ReadyMedium Hype RiskLow ConfidenceHigh
What is happening

Full-path trajectory evaluation (first seen 2026-09-02) gained a concrete tooling anchor: dsh's append-only trajectory log gives full replay of every tool call — the feature analysts call "most likely to win production teams." Maersk independently built trace-based workflows where corrections flow from production failures back into the corpus.

Why it matters

Single-request input/output assertions miss the failure modes agents actually exhibit (wrong path taken, compounding assumptions). Replay logs make agents debuggable and evaluable the way distributed-system traces did for services.

Evidence from real teams

DeepSeek (dsh default); Maersk (feedback loop of 100,000+ corrections); Navan (trajectory completeness metric); Uber uReview (addressal-rate metric).

Engineering implication

Make append-only trajectory capture a hard requirement for any new agent system; it is now cheap to adopt via dsh or your own harness. Verdict: Adopt.

3. Software-factory org design & AI-code architectural guardrails
MomentumHigh SentimentPositive Production ReadyMedium Hype RiskMedium ConfidenceMedium
What is happening

Two complementary shifts in how teams govern AI-generated code. (1) Augment's software-factory org model reassigns ownership to a spec author, a verifier, a fleet operator, and a line owner with documented halt authority — because agents absorb implementation and leave specifying/verifying/halting to people. A 2026 arXiv study of 802 developers / 196,212 PRs found PR volume grew 3.1× against baseline while the reviewer pool grew only 1.5×. (2) O'Reilly's architectural-guardrails piece names the failure mode: agents write clean, passing code that silently violates architectural decisions (e.g., bypassing an internal API), because the ADR capturing the rule sits in a directory the workflow never touches.

Why it matters

Code that compiles and passes tests can still be wrong at the architecture level. As agent-authored PR volume multiplies, the human bottleneck moves from writing code to specifying, verifying, and owning the authority to stop a line.

Evidence from real teams

Augment (published org-design guide); the arXiv enterprise study; GitHub's finding that AI code can compile/pass yet be incorrect; Unblocked's "context engine" framing of the same organizational-context gap.

Engineering implication

Pair agent rollout with named halt authority and machine-readable architectural guardrails (ADRs surfaced into the agent's context). Do not scale agent PRs past your review capacity without this. Verdict: Adopt the guardrails; Trial the formal org-design roles.

Terminology Tracker
DeepSeek Harness (dsh) — NEW

Definition: DeepSeek's MIT-licensed, TypeScript-microkernel agent runtime (CLI dsh, shipped Aug 13 2026) where the model adapter, tool registry, sandbox, session log, scheduler, UI, and even the agent loop are swappable plugins ("everything is a plugin"). Differs from Claude Code (deepest but closed, ~30 lifecycle hooks) and T3 Code (a harness manager that wraps other harnesses): dsh is an open, inspectable, replaceable harness runtime with an append-only trajectory log. 200K+ GitHub stars in ~3 weeks; production-deployment evidence still thin.

"Tribal dungeons" / SOP-as-corpus — NEW

Definition: Maersk's term for operational knowledge that exists inside an organization but in a form no agent can execute safely (e.g., legacy SOPs that are "screenshots organized in sequence"). The practice converts them into a trace-based, executable corpus (preconditions, decision points, backend calls, validation, recovery paths) that becomes the company's "process memory," roughly 20× larger than the runtime. The defining claim: "the agent is not the system; the refining loop around the agent is the system." Differs from generic RAG — the corpus is executable process logic, not retrievable documents.

Context engine / "satisfaction of search" — NEW

Definition: Unblocked's Peter Werry's framing of the agent context problem: agents are "expert engineers who forget everything" — technically capable but organizationally amnesiac, and they fall into radiology's "satisfaction of search" trap (finding one plausible answer and stopping before discovering the Slack thread or PR that holds the real rationale). A context engine ingests org knowledge (code, PRs, Slack, docs) and delivers task-specific context on demand; claimed to cut token spend roughly in half and prevent compounding wrong-assumption loops.

FRONTIER Act / Independent Verification Organizations (IVOs) — NEW

Definition: US bipartisan bill (Reps. Obernolte & Trahan) creating a federal system of licensed third-party "Independent Verification Organizations" that assess whether each "very large frontier developer" (>$5B revenue, >$10B dev spend over 3 years) has an adequate frontier-AI framework for catastrophic-risk mitigation, reported every 6 months to a new Under Secretary of Commerce for AI Security. Differs from prescriptive standards bills: it licenses the assessors and audits the framework, rather than baking technical standards into law.

Augment formalized four named roles (spec author, verifier, fleet operator, line owner with halt authority). The bottleneck is now specification/verification/halting, not implementation.

Harness engineering — EVOLVING (first seen 2026-09-01)

Strongest corroboration run yet: DeepSeek's open dsh, Maersk's "refining loop is the system," and coding-tool founders (Amp/OpenCode/Pi) publicly stating models no longer create daily-programming gaps. The thesis is moving from "emerging practice" to "consensus among shipping teams."
