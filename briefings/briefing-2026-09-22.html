Model Watch
1. DeepSeek-V4.1-Flash (open-weight, MIT)
MomentumExplosive SentimentPositive Production ReadyHigh Hype RiskMedium ConfidenceHigh
What is happening

DeepSeek released V4.1-Flash (~Sep 10), a 552B-param multimodal MoE with a Causal Encoder-Decoder (CED) architecture that projects the decoder KV cache from final encoder hidden states, activating only 8B params at prefill and 16B at decode. Compressed Sparse Attention 2 (CSA2) plus FP4 main KV caching drive the global KV footprint to 890 bytes/token — roughly 1/4 of V4-Flash and 1/437 of V1. Context is 1M tokens; license is MIT; the DeepSeek API serves it under the deepseek-flash name and is OpenAI- and Anthropic-API compatible.

Capabilities & benchmarks

At max reasoning effort it ties or leads frontier closed models on several agentic tasks: DeepSWE v1.1 74.2 (Opus-5.0 74.0, GPT-5.6 Sol 73.0), Terminal-Bench 2.1 90.6 (best-in-class), Terminal-Bench 3.0/4.0 30.0/31.2, AutomationBench 54.8 (beating Opus-5.0 50.3), Agent's Last Exam 31.8, CyberGym 88.1. Reasoning lags on pure-knowledge tasks (HLE 36.8 vs Opus 56.3) — the strength is deliberately agentic/code, not trivia. It exposes a continuously controllable reasoning_effort (1–100). 542k downloads in ~12 days.

Who is using it

Live on Novita, Fireworks, Featherless, DeepInfra with OpenAI-compatible serving; Qwen and Xiaomi cards explicitly cite Claude Code / Codex / OpenCode harness compatibility. The model is positioned as a drop-in backend for existing agent tools ("no code required").

Engineering implication

The KV-cache compression makes self-hosted long-context agent runs economically viable where they previously weren't. For teams running a two-tier stack, V4.1-Flash is now a defensible choice for the high-volume ~90% of coding/agent traffic. Verdict: Adopt for the self-hosted tier if you have vLLM/SGLang capacity; validate on your own agentic evals before displacing a frontier API on hard tasks.

Agent Engineering & AI SDLC
1. "Everything is a plugin" agent harnesses (DeepSeek Harness)
MomentumExplosive SentimentPositive Production ReadyLow Hype RiskHigh ConfidenceHigh
What is happening

DeepSeek open-sourced deepseek-harness (dsh, MIT, 233k stars / 28k forks) — an agent harness built on an "everything-is-a-plugin" architecture powered by Cordis, whose design is described in "A Programming Paradigm for Spatiotemporal Composability." It ships Minimal/Standard/PTC scaffolds and is the harness used to reproduce DeepSeek-V4.1-Flash's DeepSWE and Terminal-Bench results. The README explicitly warns: developer preview, "THERE WILL BE COMPATIBILITY-BREAKING CHANGES."

Why it matters

This is the first time a frontier-tier lab has shipped its own agent harness as open code with a benchmark-reproducible scaffold. The plugin-first model competes directly with Claude Code / Codex / OpenCode as a harness substrate and gives self-hosting teams a reference architecture rather than a black box. It also reframes "harness engineering" from a closed-lab practice to a composable, OSS layer.

Evidence from real teams

DeepSeek's own API docs list Claude Code, GitHub Copilot, and OpenCode as compatible backends alongside dsh; the DeepSeek-V4.1-Flash card publishes DSH Minimal/Standard/PTC benchmark variants against Claude Code, Codex, OpenCode, Pi, and mini-SWE scaffolds — a transparent harness-vs-harness comparison rather than a single vendor number.

Engineering implication

Worth a serious evaluation as an OSS harness option, but treat as preview: pin versions, expect breaking changes, do not yet anchor production agents on its plugin API. Verdict: Trial for non-critical agent workloads and benchmarking; Watch for production until the API stabilizes.

2. Groupwise Agentic Grading / "You Only RL Once" (self-improvement RL loop)
MomentumHigh SentimentMixed Production ReadyMedium Hype RiskMedium ConfidenceMedium
What is happening

Xiaomi's MiMo-V2.6 technical report formalizes two ideas worth tracking. "You Only RL Once": one mixed GRPO run across coding, general agents, visual, and cybersecurity in the same batch (1,568 prompts × 16 rollouts/step), so capabilities reinforce each other and transfer to unseen harnesses — replacing the per-domain-RL-then-merge norm. Groupwise Agentic Grading: binary pass/fail can't rank passing solutions, so an agentic grader builds task rubrics offline (Groupwise Reward Synthesis) and redistributes advantage toward higher-quality passing trajectories online (Groupwise Advantage Redistribution), judged against the policy's own samples — closing a self-improvement loop that steers toward shorter paths and fewer tokens.

Why it matters

This is a concrete, open recipe (MIT weights + described algorithm) for the "scale RL compute, environment diversity, and grader compute together" thesis — adjacent to the recursive-self-improvement signals tracked since Sep 21 but distinct: it is RL-loop self-improvement with an explicit anti-reward-hacking guard (environment hardening, adversarial screening, verifier cross-checks) and on-policy distillation (MOPD2) afterward. It is reproducible in a way opaque internal RSI reports are not.

Evidence from real teams

Only Xiaomi's own report so far; no independent replication. The "aligned RL" cold-start-from-self-correction step is described but not separately benchmarked. Confidence is medium precisely because the headline gains are vendor-measured.

Engineering implication

For teams building RL pipelines, the mixed-batch + rubric-grade pattern is the most actionable new idea this cycle — it directly attacks the "pass/fail can't distinguish good from mediocre passes" problem that limits RL signal on agentic tasks. Verdict: Trial the grading approach in your own RL stack; treat the model's numbers as provisional.

3. Verticalized frontier agents (Astra for Law)
MomentumHigh SentimentPositive Production ReadyMedium Hype RiskMedium ConfidenceHigh
What is happening

Astra for Law (Sep 17) packages GPT-6 Astra with a legal search index (230M+ URLs, Free Law Project/CourtListener corpus), custom instructions for legal analysis/writing, 26 partner plugins (iManage, Intapp, DeepJudge, Thomson Reuters HighQ/CoCounsel), and a Trusted Access program with Zero Data Retention. On Vals AI Legal Research Bench it passed 54.0% of questions vs 38.7% for GPT-6 Astra + web search alone — a 40% relative jump from the tooling, not the base model.

Why it matters

This is the clearest shipped example of the pattern where the competitive moat is base model + domain tools + governance, not the base model alone. It validates the broader "domain-tuned" thesis (Salesforce Koa on an open base is the open-weight counterpart) and shows forward-deployed engineers co-building firm-specific apps (Sullivan & Cromwell agreement analyzer, Ropes & Gray deal-diligence, Cooley GO Public).

Evidence from real teams

Named, shipping partners: Harvey and Legora building on the API; Sullivan & Cromwell, Ropes & Gray, Cooley, Skadden, Wachtell building custom apps; Latham & Watkins co-designing governance. This is real-team adoption, not a feature announcement.

Engineering implication

For any team building vertical agents, the lesson is to invest in the retrieval index, tool ecosystem, and governance layer as first-class engineering artifacts — that is where the 40%-relative lift came from. Verdict: Adopt the architecture pattern; Trial the Astra-for-Law product itself only if you're in legal.

Terminology Tracker
DeepSeek Harness / "everything is a plugin" — NEW

Definition: Open-source agent harness (dsh, MIT) from DeepSeek built on the Cordis framework's "spatiotemporal composability" programming paradigm, in which tools, scaffolds, and capabilities are uniformly plugins. Ships Minimal/Standard/PTC agent modes and is the harness used to reproduce DeepSeek-V4.1-Flash's DeepSWE/Terminal-Bench results. Differs from Claude Code/Codex (closed harnesses over an API) and from generic MCP tooling (it is a full harness, not just a tool protocol). Explicitly developer-preview with breaking changes.

Groupwise Agentic Grading — NEW

Definition: Coined by Xiaomi MiMo (Sep 2026) for an RL reward-scaling technique: an agentic grader compares rollouts within a group, building task-specific rubrics offline (Groupwise Reward Synthesis) and redistributing advantage toward higher-quality passing trajectories online (Groupwise Advantage Redistribution). Solves the problem that binary pass/fail cannot rank passing solutions, which weakens the RL signal on agentic tasks. Distinct from RSI (no autonomous algorithm self-editing) and from rubric-based evals (it is inside the training loop, not just a post-hoc judge).

"You Only RL Once" (mixed-batch RL) — NEW

Definition: Xiaomi MiMo's practice of running a single mixed GRPO RL batch across coding, general agents, visual, and cybersecurity domains simultaneously (rather than separate per-domain RL runs then merging), so capabilities reinforce each other and transfer to harnesses unseen in training. Contrasts with the dominant train-per-capability-then-distill norm.

Causal Encoder-Decoder (CED) / KV-cache compression — NEW

Definition: DeepSeek-V4.1-Flash architecture: a 40-layer transformer split into a 20-layer causal encoder followed by a 20-layer decoder, where the decoder's global KV cache is projected from the final encoder hidden states rather than each decoder layer's own states. Combined with Compressed Sparse Attention 2 (CSA2) and FP4 main KV, it drops the persistent KV cache to 890 bytes/token (~1/4 of V4-Flash). The engineering point: input-heavy agentic workloads activate far fewer params and store far less KV, making long-context self-hosting economical.

preserve_thinking (retained reasoning context) — NEW

Definition: Qwen3.8 feature (on by default) that retains thinking blocks from all historical messages across a conversation, maintaining a full reasoning trace across turns. Qwen argues it improves decision consistency and KV-cache utilization in multi-turn agent scenarios and reduces redundant re-reasoning — distinct from simple "extended thinking" because the trace persists across turns rather than being discarded. Worth testing as a default for long agent runs.

Adopt

Invest in the retrieval index + tool/governance layer as first-class engineering artifacts (the Astra-for-Law 40%-relative lift came from tooling, not the base model).

Trial

DeepSeek Harness for non-critical agent workloads and transparent harness-vs-harness benchmarking (pin versions; expect breaking changes).
